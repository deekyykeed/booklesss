Session management

Learn how Clerk tracks an active session across requests, how tokens are refreshed, and how to customize the session lifecycle for your application.

i
Note — Session tokens are short-lived JWTs. You never store them yourself; the SDK refreshes them in the background.

How sessions work #

When a user signs in, Clerk creates a session and issues a session token. Your middleware verifies the token with clerkMiddleware() on every request, so a page is never rendered for a signed-out visitor.

Set up session checks #

1

Install the SDK

Add the package to your application. The middleware and components ship in one package.

terminalCopy
npm install @clerk/nextjs
2

Add the middleware

Create middleware.ts at the project root and export the Clerk middleware.

middleware.tsCopy
import { clerkMiddleware } from '@clerk/nextjs/server'

export default clerkMiddleware()
3

Protect your routes

Wrap protected content and read the session anywhere with auth().

Customize the lifecycle #

Session lifetime, inactivity timeout, and multi-session handling are configured per instance in the dashboard. Changes apply to new sessions immediately.
